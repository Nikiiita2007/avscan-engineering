## Принятые решения
- Порядок байт длины кадра: little-endian (как в libs/host/protocol.hpp).
- Документы Rust-части лежат в docs/rust/.
- Handshake инициирует хост (hello → hello_ack → start → started).
- Модуль `vuln_scanner` — отдельный модуль со своим манифестом в rust/modules/. Черновик `modules/vuln_parser` (разбор URL бюллетеней) не изменяется и остаётся для будущего парсера.
- Модуль `net_analyzer` реализует уже существующий черновой манифест без изменений; тест сверяет модуль с реальным файлом манифеста.
- Модуль `log_hunter` — новый модуль со своим манифестом в rust/modules/log_hunter/ (в modules/ манифеста для него не было).
- Команды модулям: сообщения command и command_result, имя команды равно capability из манифеста; формат описан в docs/rust/COMMANDS.md.
- Модули читают файлы по командам и событиям только внутри command_roots.
- Панель этапа 9 раздаётся самим оркестратором с того же адреса и не использует внешние ресурсы.

## Заметки
- rust/Cargo.lock в репозитории устарел: в CI добавляются axum, clap, tower и другие зависимости. Нужно выполнить cargo update -w или cargo check локально и закоммитить результат.
- Rust CI (`rust-ci.yml`) запускается только при изменениях в `rust/**`.
- Транспорт Rust-оркестратора — stdin/stdout; named pipes для C++ антивируса — этап 6/7.
- Оркестратор пересылает события шины подписанным модулям (манифест `subscribes`); хост публикует события через `POST /events`. Событие `vuln_scanner.scan` обрабатывается только внутри command_roots.
- net_analyzer работает по конфигу (`pcap_paths`, `listen`) и по команде `net.analyze`. Живой захват трафика не реализован; вместо него localhost-приём pcap-потока (`tcpdump -U -w - | nc 127.0.0.1 9099`).
- log_hunter читает файлы один раз, по команде или в режиме `follow` (опрос раз в 200 мс, переживает ротацию логов).
- Базы уязвимых версий и устаревших образов — встроенные снимки, не исчерпывающие; подтверждайте находки по бюллетеням производителей.
- Код общего runtime модуля (кадры, Out, serve, проверка путей) сейчас дублируется в трёх крейтах; кандидат на вынос в общий крейт на этапе 7.
- Модули анализируют файлы в потоке протокола: большой файл задерживает ответы на ping.
